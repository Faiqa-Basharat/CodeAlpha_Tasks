## About

This site showcases UI/UX case studies, front-end skills, and work experience through an animated, single-page layout with a floating scroll-spy nav, tappable project cards that open detailed case-study modals, and a working contact form.

## Features

- 🧭 **Floating pill navigation** with scroll-spy active states
- 🗂️ **Animated case-study modals** for each project, opened from tappable cards
- 🧑‍💻 **Interactive experience timeline** switching between internship history
- ✉️ **Working contact form** that opens a pre-filled email draft
- 🎨 **Custom dark theme** — grain texture, radial gradients, Playfair Display + DM Sans pairing
- 📱 **Fully responsive** — nav, cards, and layouts adapt below 800px

## Case Studies

| Project | Description |

| **EchoSee** | Companion app for smart captioning glasses — real-time speech-to-text and live translation for the Deaf and hard-of-hearing community. |
| **RideLockr** | Smart anti-theft and tracking app for motorcycles — remote GPS tracking, engine lock/unlock, geo-fencing, and theft alerts. |
| **NeuroLab** | Five-page neuroplasticity research institute website with client-side routing, a custom hero slideshow, and a filterable research grid. |
| **Personal Portfolio** | This site — a hand-coded portfolio built to present all of the above. |
